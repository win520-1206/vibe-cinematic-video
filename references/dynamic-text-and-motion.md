# 动态文案与主体动作

用于用户指出字幕密集、位置单一或画面像演示文稿时，也作为新作品的默认制作方向。保留完整确认稿，减少同屏叠加和重复叙述；不是删掉科学条件或把长句全部变成更大的字。

## 先设计过程，再放文字

逐镜确定对象的起始、发展、结果和必要停留。区分主体变化、相机观察和装饰运动。只有背景飘动、镜头缩放或图表入场，不能代替机制的演示。

前后镜尽量通过同一对象、路径或可追踪结果衔接。使用稳定对象ID和统一时间，不在每个场景重置同一组点阵。具体科学题材必须单独设计，不能把所有内容映射为一个旋转球。

物体散开、形成结构、穿越空间、进入统计区间、逐步留下结果，都应对应知识。相机有预备、推进、缓冲和落定；阅读阶段减少干扰。干净切镜可以保留，不强制所有镜头都做变形。

## 完整确认稿与分时呈现

保留captions及独立script-manifest作为完整母本，SRT仍导出母本。新项目presentation.mode为full-dynamic；旧配置没有此字段时维持legacy，不改写旧作品。

每条确认稿可以对应多个textCues，用sourceId关联。片段按时间顺序拼接必须与原句完全一致，包括数值、条件和标点；不能为字效漏掉否定、范围或假设。默认按标点给出初步拆分，作者必须结合动作重新检查节奏。

每个片段都有进入、稳定阅读和退出阶段。阅读密度按稳定阶段计算。标题、解释句、注释分别有用途：不要默认同时显示顶部标题、底部整句和常驻说明；不要让同一句话在多个位置重复出现。默认只有一组主要文案，允许无文字的主体演变段落。

## 文字角色和配置

- main：参与叙事的短语或结论，按画面选择左、右、居中或底部。
- label：贴近对象的标签，使用anchor跟随，保持文字水平和可读。
- formula：需要稳定窗口的公式与数据；字效结束后停止大幅移动。

scene.textCues可覆盖自动拆分；scene.annotations可以添加首次需要时出现的模拟说明。注释必须标记annotation，完整科学依据继续写入sources.md。scene.title/science保留为元数据，不在动态模式自动常驻。

```json
{
  "id": "phrase-a",
  "sourceId": "confirmed-line-a",
  "text": "原稿中的完整片段，",
  "start": 2,
  "end": 5,
  "role": "main",
  "placement": "left",
  "effect": "mask",
  "enterSeconds": 0.25,
  "exitSeconds": 0.2,
  "emphasis": ["完整片段"]
}
```

此处时刻只是字段示例，不是新项目默认值。start/end是绝对分集秒数，并需对齐项目帧率。文本进入由该cue时刻触发，eventId将关键词强调或相关动作关联到共享事件，不能维护互不相干的时钟。

placement支持left/right/center/bottom/anchor；x/y/width为画幅比例。锚定使用anchor:{id,offset:{x,y}}。示例主体支持walker-ID；新增科学对象应在运动模块登记其稳定ID，并扩展对应校验。label持续跟随对象，main锚定文本在阅读开始后冻结位置。锚定自动限制到画幅范围，仍需检查换行与主体遮挡。

effect支持mask（遮罩揭示）、relay（短语接力）、path（路径入场）、follow（对象跟随）、emphasis（短暂强调）和none。path接受起终两个偏移点，阅读阶段停在终点；follow要求对象锚点。字效用于引导注意，不让整句不停飞动、旋转或闪烁。

## 主体与镜头接口

motion配置可声明developStart/developEnd、expect和camera。camera提供fromZoom/toZoom、panX/panY和yaw；场景衔接继承前一镜相机状态。运动阶段为prepare/develop/hold，expect可选择subject或hold；只有明确的阅读/结果停留才标hold。

随机游走示例中，walker-0逐步走过真实采样轨迹，随后进入终点统计；其他样本经过同一模型生成并落入对应区间。数值累积只统计实际到达的样本。边界相机连续，轨迹退出与新对象发展重叠组织，不通过换页重启。

## 检查边界

检查片段覆盖、主要文案并发、重复文字、稳定阅读时间、入退场与路径端点、对象锚定和横竖屏布局。有意过渡重叠使用相同overlapGroup，不能用它豁免两个阅读块的遮挡。

动效记录分别保存主体模型坐标、相机和到达计数，避免相机或背景运动冒充主体活动。脚本中的状态只能辅助判断；仍需查看实际关键帧和连续变化。主体持续静止、只有装饰在动是复核提示；明确hold阶段不因此失败。

参考素材只用于学习信息节奏、对象变化与构图机制，不复制其文案、影像、商标或水印。保持此前音乐与配色偏好；新曲重新分析，不固定历史片长或卡点。
